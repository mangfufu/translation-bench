# Translation Bench（翻译工作台）

一个面向本地 OpenAI 兼容模型服务的批量文档翻译工具。界面采用三栏布局：左侧配置、中间任务队列、右侧原文与译文对照。

## 功能

- 批量导入 Markdown 和纯文本文件
- 流式显示当前译文
- 总任务进度与当前文件进度
- 失败任务自动重试、手动重试和优先处理
- 原文与译文逐行对照，可拖动调整栏宽
- 滑动上下文保持术语、称谓和语气一致
- 剧情、技术、字幕、商务、学术等翻译风格
- 保留 Markdown 标题、列表、引用、行内标记和代码块
- 刷新页面后恢复本地任务列表，并识别已经生成的匹配结果

## 环境要求

- Python 3.10 或更高版本
- 一个提供 `/v1/chat/completions` 接口的 OpenAI 兼容模型服务，例如 llama.cpp `llama-server`
- 现代桌面浏览器

后端仅使用 Python 标准库，不需要安装第三方 Python 包。

## 快速开始

1. 单独启动你的模型服务，并确认其 OpenAI 兼容接口可以访问。
2. 启动翻译工作台：

   ```powershell
   python app.py 9000
   ```

3. 浏览器访问 <http://127.0.0.1:9000>。
4. 在左侧填写模型服务地址、模型名和必要的 API 密钥，然后点击“测试连接”。
5. 拖入 `.md` 或 `.txt` 文件并开始翻译。

Windows 用户也可以复制 `start.example.bat` 为本地 `start.bat` 后使用。`start.bat` 已被 Git 忽略，适合加入你自己的模型启动路径或本机设置。

## 默认配置

| 配置 | 默认值 | 说明 |
|---|---:|---|
| 服务地址 | `http://127.0.0.1:8081` | OpenAI 兼容模型服务 |
| API 密钥 | 留空 | 服务未启用鉴权时无需填写 |
| 模型名 | `hy-mt1.5-1.8b` | 应与服务端公开的模型名一致 |
| 上下文长度 | `65536` | 不应超过服务端实际上下文长度 |
| 每批段落 | `15` | 单次请求中的最大段落数 |
| 每批字符 | `12000` | 单次请求的字符预算 |
| 参考上文字符 | `4000` | 用于保持术语和语气一致，设为 `0` 可关闭 |
| 翻译风格 | 自动判断 | 也可以选择固定风格 |

## 输出与页面恢复

翻译结果保存在本地 `outputs/` 目录，并可从网页单独下载或打包下载。输出文件会添加目标语言后缀，例如 `.zh.md`、`.en.txt`。

任务列表和可用的原文内容会保存在当前浏览器的本地存储中；刷新页面时会尝试接回仍在同一后端进程中运行的任务。后端进程重启后，未完成的模型请求不会继续，但网页可以依据源文哈希和目标语言识别 `outputs/` 中已经完成的结果。`outputs/` 和运行生成内容不会提交到 Git。

## 提示词优先级

程序固定使用以下优先级：

```text
硬性规则 > 用户补充要求 > 风格偏好
```

硬性规则由后端维护。“补充要求”默认留空，只用于术语指定、人名保留等额外要求。

## 安全说明

- 不要把真实 API 密钥写入源码、README 或启动脚本。
- API 密钥只应在本地界面中填写；未配置密钥时，后端不会发送 `Authorization` 请求头。
- 不要提交原文、译文、模型文件、日志、交接文档或本机专用启动脚本。
- 服务默认只监听 `127.0.0.1`。本项目没有面向公网部署所需的用户认证与权限隔离，请勿直接暴露到公网。
