# 示例文件

这里存放用于手动检查翻译效果和格式保持能力的小型公开示例；自动化回归测试位于项目根目录的 `tests/`。

| 编号 | 示例 | 主要检查内容 |
|---:|---|---|
| 01 | 日文连续对话 | 连续对白、称谓与语气 |
| 02 | 日文剧情上下文 | 剧情段落与上下文一致性 |
| 03 | 英文 Markdown | 标题、列表、引用和行内格式 |
| 04 | 短句、空行与符号 | 空行、短句和特殊字符 |
| 05 | 英文长篇 | 长文上下文与跨段一致性 |
| 06 | SRT 字幕 | 序号、时间轴与字幕正文 |
| 07 | WebVTT 字幕 | cue id、时间轴和控制区块 |
| 08 | DOCX | Word 容器、样式与结构保持 |
| 09 | EPUB | 阅读顺序、XHTML 与资源保持 |
| 10 | PDF | 带文字层 PDF 的原位替换 |

这些文件可以直接拖入工作台。运行结果会写入 `outputs/`，不应提交到 Git。
